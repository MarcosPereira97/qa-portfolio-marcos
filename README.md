qa-portfolio-marcos
====================

Meu portfólio central de QA/SDET — reúno estratégia de testes, casos de teste, exploratory charters, bugs de exemplo e referências de frameworks que uso nos meus projetos.

Este repositório não contém código de automação (isso está nos repositórios de cada projeto). Aqui está o meu raciocínio por trás dos testes: como penso risco, cobertura, priorização e comunicação de qualidade.
