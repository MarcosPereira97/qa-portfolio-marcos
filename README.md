qa-portfolio-marcos
====================

Portfolio central de QA/SDET de Marcos Henrique Pereira Junior — reune estrategia de testes, casos de teste, exploratory charters, bugs de exemplo e referencias de frameworks usados nos meus projetos.

Este repositorio nao contem codigo de automacao (isso esta nos repositorios de cada projeto). Aqui esta o raciocinio por tras dos testes: como penso risco, cobertura, priorizacao e comunicacao de qualidade.
