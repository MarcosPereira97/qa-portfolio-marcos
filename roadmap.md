Roadmap do Portfolio
=====================

Proximos passos planejados para evolucao deste portfolio e dos projetos vitrine, organizados por fase do plano de padronizacao do GitHub.

## Concluido

- [x] Padronizar nomenclatura e descricao dos repositorios vitrine.
- [x] Aplicar template padrao de README (com secao de Estrategia de QA) nos projetos Cypress, Selenium e Appium.
- [x] Adicionar GitHub Actions (CI) aos repositorios que ainda nao possuiam pipeline.
- [x] Criar artefatos manuais de QA neste portfolio (test-strategy, test-cases, exploratory charters, bug reports).
- [x] Revisar e limpar arquivos desnecessarios (relatorios temporarios, configs locais) dos repositorios vitrine.

## Curto prazo

- Expandir exemplos de bug reports com casos reais de API.

## Medio prazo

- Construir novo projeto de automacao mobile usando o app de referencia do [Taqwright](https://github.com/Taqwright/taqwright-demo/tree/main/app), comparando Appium tradicional com Mobilewright e Taqwright.
- Publicar relatorios de execucao (Allure/TestDino) via GitHub Pages para os projetos vitrine.
- Criar device-matrix.md documentando cobertura de dispositivos/OS testados (quando houver mais projetos mobile no portfolio).

## Longo prazo

- Revisar periodicamente este portfolio a cada novo projeto relevante concluido.
- Avaliar inclusao de testes de acessibilidade como nova frente de atuacao.
